# SysMonX ↔ 20-Day Training Mapping

| Days | Module | SysMonX evidence |
|---|---|---|
| 1–2 | Computer Architecture – Hardware | CPU architecture, cores, memory, hardware/software path |
| 3–4 | Computer Architecture – Network | Network interfaces and RX/TX statistics; add TCP/UDP socket work if taught |
| 5–6 | Linux OS + Git | /proc, /etc/os-release, POSIX APIs, Makefile, Git workflow |
| 7–10 | C++ Programming | C++17 classes, structs, STL containers, modular code |
| 11–13 | Linux System Programming | open/read/close, /proc, dirent, uname, signals |
| 14–15 | Linux Device Drivers | Character-driver starter, /dev/sysmon design; complete ioctl yourself |
| 16–17 | Computer Architecture – Software | user/kernel boundary, process/executable concepts, architecture identification |
| 18–19 | SDLC + Agile | requirements, design, sprints, tests, Git evidence |
| 20 | Capstone | final integration, presentation, GitHub and report |

Do not fabricate progress evidence. Capture genuine screenshots, commit history and test results.
