# Six-Stage Project Process

## Stage 1 – Project Introduction
Problem, objective, scope, expected outcome.

## Stage 2 – Requirements & Development Plan
Functional/non-functional requirements, modules, deliverables and timeline.

## Stage 3 – System Design & Architecture
Architecture, component diagram, class diagram, sequence diagram, state machine and data structures.

## Stage 4 – Initial Implementation & Prototype
C++ monitor, /proc collection, network information, initial driver and first integration attempt.

## Stage 5 – Testing, Integration & Improvement
Unit tests, integration tests, error handling, performance and debugging.

## Stage 6 – Final Implementation & Presentation
Final source, UML, tests, report, GitHub repository and demonstration.
